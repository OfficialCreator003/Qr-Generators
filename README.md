## 📂 Project Structure

# 🔳 javascript html css qr-code generator webapp
A simple, clean, and customizable **QR Code Generator** built using **HTML, CSS, and JavaScript**.  
This project allows users to generate QR codes from URLs with custom colors and optional logo embedding.



## 🚀 Features

- 🔗 Generate QR codes from any URL
- 🎨 Custom foreground and background colors
- 🖼 Upload and embed logo inside QR
- ⚡ Instant QR preview
- ⬇ Download QR code as PNG
- 🧠 Auto URL correction (adds https:// if missing)
- ❌ Input validation and error handling
- 📱 Responsive and lightweight UI



## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- QR Code Styling Library
